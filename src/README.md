# src/ - 代码

> 项目所有可复用的代码统一放这里。**实验相关的代码请走 `experiments/` 下的子目录**，这里只放被多次复用的"基础库"。

## 目录组织

```
src/
├── <模块名>/         # 一个独立可复用的功能单元
│   ├── __init__.py
│   ├── README.md     # 模块说明：做什么、怎么用、被谁引用
│   └── tests/        # 单元测试（推荐）
├── notebooks/        # 探索性 Jupyter notebooks（不直接进论文）
└── utils/            # 跨模块共用的小工具函数
```

## 约定

- 每个模块自带 `README.md`：写清**输入输出、依赖、最少调用示例**
- 重要函数加 docstring（中文/英文均可，保持统一）
- 新模块要先有 `tests/` 跑通才能合入 main
- 一次 PR 只做一件事（新增/重构/修复其一）

## 与实验的关系

- 一次实验在 `experiments/<日期>-<编号>-<主题>/run.sh` 里调用 `src/`
- 修改 `src/` 的代码会同时影响多个实验——PR 描述里必须写明"会影响哪些实验结果"
