# docs/ 目录

项目文档统一放这里，按主题分子目录：

```
docs/
├── 01-项目说明/     # 项目背景、目标、里程碑
├── 02-周报进度/     # 周期性进度汇报
├── 03-模板/         # 可复用模板（周报模板、文件清单等）
├── 04-资料归档/     # 共享的资料文件（可含 PDF、表格等小文件）
└── 待整理/          # 还没想好放哪的内容，Review 时归类
```

> 约定：单个文件超过 10MB 请走 GitHub Releases，不要放进 Git 仓库。
> 新内容请先发起 Pull Request，审核通过后才会进入 main。
